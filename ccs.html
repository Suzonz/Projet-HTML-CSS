CSS

CSS est l’acronyme de « Cascading Style Sheets » ce qui signifie « feuille de style en cascade ».

Le CSS représente un langage informatique dédié à la mise en forme visuelle des documents web. Parmi ses nombreuses fonctionnalités, le CSS permet, entre autres, de gérer l’aspect typographique, la disposition des blocs, les couleurs, les animations et bien d’autres propriétés visuelles incontournables.

La syntaxe

La syntaxe du CSS repose sur différents éléments clés permettant de cibler les éléments HTML et de définir leurs styles :

Exemple de syntaxe CSS par lucidar.me

Les sélecteurs identifient les éléments HTML ciblés par les règles CSS :

  • h1 {...} Cible tous les éléments h1
  • #section {...} Cible l'élément avec l'id « section »
  • .title {...} Cible les éléments avec la classe « title »

Les propriétés définissent les caractéristiques visuelles à styler (couleur, taille, marges…) :

  • color: Définit la couleur du texte
  • font-size: Définit la taille de la police
  • margin: Définit une marge extérieure

Les valeurs spécifient l’aspect concret à donner à chaque propriété :

  • color: blue; Colore le texte en bleu
  • font-size: 18px; Définit la taille de le police à 18px

Les déclarations sont l'ensemble comprenant une propriété et une valeur :

  • height: 20px; Est une déclaration composée de la propriété "height" et de la valeur " 20px"

Les fonctionnalités principales

Avec l’évolution constante des standards web, le CSS (et notamment dans sa dernière version majeure, le CSS3) a apporté de nombreuses fonctionnalités avancées pour enrichir l’expérience visuelle des sites internet :

Le CSS3 permet de créer des effets graphiques sophistiqués directement dans le navigateur, sans avoir recours à des images

  • background: linear-gradient (to right, salmon, lemonchiffon);

Définit le fond en un dégradé de couleur, entre celles sélectionnée, ici "salmon" et "lemonchiffon"

Les transitions CSS offrent un moyen simple d’animer les changements d’état d’un élément, tandis que les animations permettent de créer des séquences plus complexes : 

  • a {color: black;} 
    a:hover {color: red;}

Définit le changement de couleur du texte, passant du noir au rouge lorsque la souris passe dessus

  • Rotate

Ajoute une animation de rotation au texte

Ce fichier peut être lu de cette manière :

  • Ligne 1 à 3 : body { } indique que le style s'applique au body
  • Ligne 2 : background-color: darkseagreen; définit la couleur du fond en "darkseagreen"
  • Ligne 5 à 7 : h1 { } indique que le style s'applique au titre h1
  • Ligne 6 : font-family: Arial, Helvetica, sans-serif; definit la police en Arial
  • Ligne 7 : font-size: 40px; définit la taille de la police à 40px
  • Ligne 10 à 13 : p { } indique que le style s'applique au paragraphe
  • Ligne 11 : color: gold; définit la couleur "gold" pour le texte
  • Ligne 7 : font-size: 40px; définit la taille de la police en plus large qu'originalement
