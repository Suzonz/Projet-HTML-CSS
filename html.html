HTML

HTML signifie « HyperText Markup Language » on peut le traduire par « langage de balises pour l'hypertexte ».

C'est un type de langage informatique qui décrit au navigateur comment afficher la page. Pour faire cela, il va définir les éléments de contenu tels que les titres, les paragraphes, les images, les liens ou encore les vidéos.

Les Balises

Les balises HTML sont les éléments de base du codage HTML. Elles sont utilisées pour mettre en forme un texte, structurer et hiérarchiser le contenu d'une page. Les balises indiquent également au navigateur comment afficher la page en question. Pour l'internaute, elles sont invisibles sauf s'il affiche le code source.

Anatomie d'un élément HTML

Chaque élément HTML suit une structure simple mais solide :

Anatomie d'un élément HTML par Mozilla Developer Network

  • Balise d'ouverture ou ouvrante : Signale le début de l'élément et inclut souvent des attributs qui fournissent des informations supplémentaires sur l'élément. Par exemple, la balise : <p> indique le début d'un paragraphe
  • Contenu : Il s'agit de l'information que l'élément représente, comme du texte, des images ou d'autres éléments HTML. Dans notre exemple de paragraphe, le contenu serait le texte proprement dit du paragraphe
  • Balise de fermeture ou fermante : Elle marque la fin de l'élément. Les balises de fermeture sont identiques aux balises d'ouverture, mais elles sont précédées d'une barre oblique (/). Pour notre paragraphe, la balise de fermeture serait </p>

A quoi ressemble un fichier HTML

Voici un exemple de fichier HTML :

Ce fichier peut être lu de cette manière :

  • Ligne 1 : <DOCTYPE> indique le type du document, soit HTML
  • Ligne 2 : <lang> indique la langue. Ici nous avons lang="fr" la page sera donc en français
  • Ligne 4 à 8 : <head> permet de rentrer des données qui seront invisibles à l'utilisateur
  • Ligne 7 : <title> indique le titre qui sera apparaitra sur l'onglet du navigateur
  • Ligne 10 à 13 : <body> contient tout ce qui va apparaitre sur la page web (titre, paragraphe,img, etc)
  • Ligne 11 : <h1> indique le titre principale de la page.
  • Ligne 12 : <p> contient un paragraphe
